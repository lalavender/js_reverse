## 第二步：运行拦截 — `watch()` 代理

### 核心工具

一个 Proxy 包装函数，拦截所有 `get/set/apply`，打印日志。

```js
function watch(obj, name) {
  return new Proxy(obj, {
    get(target, prop) {
      const val = Reflect.get(target, prop);
      console.log(`取值: ${name}.${String(prop)} =>`, val);
      return val;
    },
    set(target, prop, value) {
      console.log(`设置值: ${name}.${String(prop)}`, '=>', value);
      return Reflect.set(target, prop, value);
    },
    apply(target, thisArg, args) {
      console.log(`调用: ${name}(...)`, args);
      return Reflect.apply(target, thisArg, args);
    }
  });
}
```

### 用法

```js
window = watch(window, 'window')
document = watch(new Document(), 'document')
navigator = watch(new Navigator(), 'navigator')
```

### 日志解读

```
取值: window.insight => undefined              ← 缺少 insight 对象
取值: window.xhsFingerprintV3 => undefined     ← 缺少指纹对象
取值: document.cookie => "abRequestId=..."    ← cookie 已有（硬编码）
调用: performance.now() []                     ← 正常调用
设置值: window.mnsv2 undefined => [Function]   ← 函数已定义
```

## 第三步：分类补全 — 按优先级

### 第一优先级：原生构造函数

```js
window.Object = Object      // 直接指向 Node.js 原生
window.Function = Function
window.Array = Array
window.String = String
window.Date = Date          // ★ 不要覆写 Date！env.js 直接用原生 Date
window.Math = Math
window.JSON = JSON
window.RegExp = RegExp
window.Error = Error
window.Reflect = Reflect
window.Promise = Promise
```

这些原生构造函数会被用来做类型判断、原型链操作，**直接复用 Node.js 自带的即可**。

### 第二优先级：运行时数据

```js
// cookie —— 从浏览器复制（硬编码）
document.cookie = 'abRequestId=xxx; a1=xxx; ...'

// navigator —— 固定值即可
navigator.userAgent = 'Mozilla/5.0 ...'
navigator.platform = 'Win32'
navigator.language = 'zh-CN'
navigator.webdriver = false

// location —— 需要和目标页面一致
location.href = 'https://www.xiaohongshu.com/'
location.hostname = 'www.xiaohongshu.com'

// screen —— 固定分辨率
screen.width = 1920
screen.height = 1080
screen.colorDepth = 24
```

**原则：** 用真实浏览器捕获的值，直接硬编码。

### 第三优先级：计算型 API

这些函数必须返回**合理的假数据**，而不是 `undefined`：

```js
// performance.now 必须返回数字（不是 undefined！）
Performance.prototype.now = function() { return Date.now() }

// canvas 指纹必须返回合理值
CanvasRenderingContext2D.prototype.measureText = function(text) {
  return { width: text.length * 10 }
}
CanvasRenderingContext2D.prototype.getImageData = function(x,y,w,h) {
  return { data: new Uint8ClampedArray(w * h * 4) }
}
```

#### 关键陷阱：writable 默认为 false

`Object.defineProperties` 定义的属性 `writable` 默认为 `false`，直接赋值会静默失败！

```js
// ❌ 这样不行（原型属性 writable=false，赋值被忽略）
Performance.prototype.now = function() { return Date.now() }

// ✅ 这样才行：在实例上用 defineProperty
Object.defineProperty(performance, 'now', {
  value: function() { return Date.now() },
  writable: true, configurable: true
})
```

### 第四优先级：业务特有对象

这些是目标网站特有的对象，从浏览器捕获后简化：

```js
// 从浏览器捕获原始对象（用 safeStringify 处理循环引用）
// 简化到只保留 code.js 实际用到的属性
window.insight = {
  sessionId: 'e23ef894-...',   // code.js 读取这个
  version: '1.3.14',
  queue: [],
  isReady: true,
}

window.xhsFingerprintV3 = {
  getV18: function() { return 'v18_xxx'; },
  getCurMiniUa: function() { return 'Mozilla/5.0 ...'; },
  // ... 其他空函数
}
```

### 第五优先级：特殊对象

```js
// WebAssembly.Instance — code.js 内部创建
window._99c63f0b659b4ee2ef17c642a0d345eb = new WebAssembly.Instance(...)
// 如果不需要实际 WASM 功能，可以留空或 mock
```

**这些值通过 watch 日志发现，按需添加即可。**

## 真实案例分析

### 案例 1：performance.now 返回 undefined

**现象**: code.js 调用 `performance.now()` 时返回 `undefined`

**根因**: `Object.defineProperties(Performance.prototype, { now: {value: ...} })` 的 `writable` 默认为 `false`

**修复**:
```js
// 在实例上定义（绕过了原型 writable:false）
Object.defineProperty(performance, 'now', {
  value: function() { return Date.now() },
  writable: true
})
```

### 案例 2：window.mnsv2 未定义

**现象**: `typeof window.mnsv2 === 'undefined'`

**根因**: code.js 的初始函数 `_AUuXfEG27Xa3x` 检查 `window.insight` 和 `window.xhsFingerprintV3`，缺失导致提前退出

**修复**: 从浏览器捕获这两个对象，简化后补入环境

### 案例 3：demo.js 的 Date 覆写导致初始化失败

**现象**: demo.js + code.js 加载后 mnsv2 为 undefined，但 env.js + code.js 正常

**根因**: demo.js 覆写了 `Date` 构造函数，`new Date()` 返回的时间与浏览器行为不一致

**修复**: 注释掉 Date 覆写，使用原生 Date

### 案例 4：file:// URL 导致 location.setter 崩溃

**现象**: `this.protocol = a[1] ? a[1] : ""` → TypeError

**根因**: `file://` 路径的 URL 正则匹配不到 protocol

**修复**: 确保 location 的 href 使用 `https://` 协议

## 核心原则

1. **按需补充，不多给一个 API** — 先让代码跑起来
2. **优先模拟数据，再模拟行为** — cookie、navigator 等数据优先
3. **不要覆写内置构造函数** — Date、Array、Map 等直接用原生的
4. **watch 日志是你的向导** — 看到 undefined 就补，看不到就不补
5. **非确定性值不影响验证** — 签名每次不同是正常的
6. **极简环境更稳定** — 环境越复杂，越容易出问题
